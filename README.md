# MineBot

MineBot — это **панель управления** + **бот**, которые работают локально на Windows.

## Как это устроено
- **`MineBot.exe`**: тонкий лаунчер (Tauri). Почти не меняется.
- **Панель (web UI)**: живёт локально и открывается в окне `MineBot.exe`.
- **BotService**: отдельный локальный сервис, который запускает Java‑движок и отдаёт API/логи панели.
- **Данные/настройки**: хранятся в `%APPDATA%\\MineBot` (то есть `C:\\Users\\<user>\\AppData\\Roaming\\MineBot`).

## Требования (Windows)
- **Node.js** (нужен для `runner.js`, панели и BotService)
- **Java** (нужен для движка бота)
- **WebView2 Runtime** (для окна `MineBot.exe`)

Если чего-то не хватает — `MineBot.exe` покажет страницу с ссылками на установку.

## Запуск из исходников
```powershell
npm install
node .\runner.js
```

Панель будет доступна по адресу `http://127.0.0.1:3847/home`.

## Подключение/авторизация
- Параметры подключения вводятся в панели и сохраняются **локально** в `%APPDATA%\\MineBot\\settings.local.json`.
- Авто‑авторизация работает **только по подсказкам из чата**: бот ждёт сообщения, где сервер явно просит выполнить `/register` или `/login`, и только после этого отправляет команду с задержкой.

## Обновления
Кнопка “Проверить обновления / Обновить код” в панели обновляет **код панели и BotService** (который хранится в `%APPDATA%\\MineBot\\app`).
`MineBot.exe` стараемся обновлять как можно реже.
